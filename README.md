# Gym Las Américas — landing demo

Landing de una página para **Gym Las Américas**, gimnasio de barrio en Hatillo, San José, Costa Rica.
Demo de referencia hecha por Nocodeveloper: precios, horarios, entrenadores y testimonios son **datos de ejemplo**.

- `index.html` autocontenido (CSS y JS inline, mobile first, iconos SVG).
- Formulario de prueba gratis que arma el mensaje y abre WhatsApp (`+506 8841 9907`).
- Imágenes libres de Unsplash en `img/`, recomprimidas con PIL.
- Build: `Dockerfile` sobre `nginx:alpine`.

Publicado en: https://clientes-demo-gymlasamericas.rddxeh.easypanel.host
